Novo AI Visibility Orchestrator

Full-Stack / AI Engineer April 2026

An agentic SEO/AEO audit platform that crawls any URL and orchestrates six specialized AI agents to score a page's traditional search readiness (SEO) and its AI-answer-engine readiness (AEO) across five weighted signals each. Beyond scoring, it surfaces missing keywords and unanswered buyer questions, generates draft title/meta tags and a FAQPage JSON-LD schema, runs a competitor gap analysis against rivals, and applies a compliance check that blocks risky insurance claims — every recommendation labeled draft for human review, nothing auto-published.

In live QA it found that adding a single FAQPage JSON-LD schema would lift the target's AEO score from 66 to 86 — a concrete, high-leverage fix. Built with a FastAPI backend, a React + Vite + Tailwind frontend, a BeautifulSoup crawler, and SQLite audit history; backed by 45 pytest tests and deployed on Railway + Vercel using a Claude Code + GStack agentic development workflow.

B2B Review Automation SaaS

Lead Engineer July 2025

A full-stack SaaS platform that automates B2B customer-review outreach across SMS and email, giving businesses persistent scheduling, real-time delivery tracking, and customer-behavior analytics from a single dashboard. Built on FastAPI with SQLAlchemy ORM over PostgreSQL (Supabase), with APScheduler driving hourly background jobs that send review reminders on a recurring cadence.

The core engineering challenge was concurrency: under overlapping scheduled runs the system could fire duplicate messages to the same customer. I eliminated the race condition by enforcing a PostgreSQL composite unique constraint at the database layer, guaranteeing idempotent sends regardless of timing. The API surface is a set of secure, modular REST endpoints with Pydantic validation and JWT auth; the React + Tailwind frontend is deployed on Vercel with the backend on Render, and communication pipelines run through Twilio and SendGrid.

LLM-Powered Financial RAG System

AI Engineer May 2025

A Retrieval-Augmented Generation pipeline that answers complex natural-language questions over dense SEC 10-K filings. Raw filings are parsed and chunked, embedded with OpenAI's text-embedding-3-small model, and indexed in a scikit-learn k-NN store; at query time the system performs cosine-similarity top-k retrieval to ground the LLM's answer in the actual source text rather than its training data.

The result is investor-ready QA that stays faithful to the filings — achieving 60%+ F1 accuracy on a benchmark question set at a cost of under $0.10 per query, demonstrating that grounded, high-quality financial QA can be delivered cost-efficiently. Built with LangChain to orchestrate the retrieval-and-generation flow.
